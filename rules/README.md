手册是 **26 页扫描件**（无文字层，需 OCR 或逐页阅读）。关键章节位置：

| PDF 页 | 内容 | 本项目关注度 |
|---|---|---|
| 1 | 封面 | — |
| 2–3 | 目录 | — |
| 7–8 | 赛事概况、奖项设置 | ★★★ 特等奖需兼报两赛道 |

## 2 模板解析要点

```
第 1 行：标题（含队名与成员）
第 2 行：表头 序号,OPR_DT,OPR_HR,INTERVALSTARTTIME_GMT,INTERVALENDTIME_GMT,storage_power_mw
第 3–26 行：24 个时段数据
末尾：说明行（内部含 3 处裸 LF）
```

四个易错点：

1. `OPR_HR` 是 **1–24**，不是 0-based 的 `H:00:00`。
2. 日期 `yyyy/m/d`，**月日不补零**（`2026/12/6`）。
3. GMT 偏移字面量恒为 **`-00:00`**，不是 `+00:00` 也不是 `Z`。
4. **HR17 起 GMT 日期已进入次日，`OPR_DT` 不变**，不能按 GMT 日期分组。

### 2.1 ⚠ 模板自带的示例曲线不可行

模板里有一条示例曲线，**照抄它 = 当日全天收益归零**。

| 时段 | 示例值 | 问题 |
|---|---|---|
| HR12/13/14 | −7 / −7 / −0.82 | 充电段正确，末态 13.297 MWh，距上限仅 0.003 MWh |
| HR17/18/19 | **+10** / +10 / +10 | 超 Pmax=7 MW；SOC 跌至 **−157%** |

验证过程见 [`../docs/02-规则详解.md`](../docs/02-规则详解.md#8-官方示例曲线为什么不可行)。

> 这条观察同时给出一个正面信息：**充电段是精确反解的**（余量 0.003 MWh），说明官方资产参数与符号约定（正放负充）与我们的实现一致，且**最优解本就贴着边界**。

## 3 版本历史

| 版本 | 日期 | 变化 |
|---|---|---|
| V3.0 | 2026-11-19 | **提交模板破坏性变更**：4 列 → 6 列；`OPR_HR` 改 1–24；日期格式改 `yyyy/m/d`；明确「以最后一次为准」；新增同分规则（去掉 100 上限）；明确末日 SOC 不约束 |
| 早期版本 | 2026-10 | 赛期、储能参数、评分公式与 V3.0 一致 |

**只有提交格式变了，物理规则和评分机制没变。** 这一点很重要——意味着赛前做的全部策略论证与实测结论在 V3.0 下仍然成立，只需适配文件格式。
